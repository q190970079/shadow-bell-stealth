Shadow Bell — a top-down stealth game. You are a silent thief in a moonlit gallery: slip past patrolling guards whose vision cones are raycast against the walls, hide in bushes, slip behind crates, collect all three moon bells to wake the exit, and slip out unseen. Three galleries, each with more patrols; suspicion builds while a guard stares and decays when you break line of sight, so a near miss can still be recovered. Keyboard (WASD/arrows, Shift to run — loud!) and mouse (click to walk there), with WebAudio footsteps, pickup chimes and alarm stings. No network needed: the whole game is static files under `game/`.

## Run it

```sh
python3 -m http.server 8321 --directory game
# open http://localhost:8321 in desktop Chrome, then press Enter
```
